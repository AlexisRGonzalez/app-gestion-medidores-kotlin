# App Gestión de Medidores Kotlin

Aplicación Android desarrollada en Kotlin para el registro y gestión de medidores domiciliarios.

## Descripción

Proyecto desarrollado durante mi formación como Técnico en Informática, orientado al desarrollo de aplicaciones Android.

La aplicación permite gestionar información relacionada con medidores domiciliarios mediante una interfaz móvil, utilizando una estructura basada en componentes de Android y almacenamiento local.

## Tecnologías utilizadas

- Kotlin
- Android Studio
- Jetpack
- Room
- Gradle

## Características

- Registro y gestión de medidores domiciliarios.
- Almacenamiento de información mediante Room.
- Interfaz desarrollada para dispositivos Android.
- Arquitectura basada en componentes de Android.
- Persistencia de datos local.
